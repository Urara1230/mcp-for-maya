# AGENTS.md — Maya MCP Server

MCP server for LLM agents to inspect, plan, and edit Autodesk Maya scenes through structured tools.

## Install / run / test
uv sync --frozen
python -m maya_mcp_server -vv
uv run python -m pytest tests/ -q          # stub tier
uvx ruff@0.17.1 check . --output-format=json --exit-zero > ruff-report.json          # lint report: red findings must not fail the shell
python .github/scripts/check_ruff_budget.py ruff-report.json .github/ruff-baseline.json   # lint gate: frozen per-rule budget
uv run python -m mypy src/ > mypy-report.txt; uv run mypy-baseline filter < mypy-report.txt   # type-check gate: mypy's raw exit is non-zero by design (baselined errors); the filter is the verdict
uv run pre-commit run --all-files          # hook sweep (the why is in CONTRIBUTING's dev setup)

## Gates
A "governance gate" is any check a job runs in `.github/workflows/ci.yml`; `.github/gate-registry.yaml` indexes every enforced one with its pins, and `check_gate_registry.py` fails an unregistered or unwired entry, so neither list can rot quietly. To see what CI actually runs, read the `run:` lines: `grep -E 'run: python .github/scripts' .github/workflows/ci.yml`. The three baseline ratchets only ever move down — ruff budget and monolith line budget are `lint` steps, the mypy baseline is its own job.

## Don't touch
- `src/maya_mcp_server/maya_scene_module.py` is line-capped by `.github/monolith-budget.json`; new Maya-side capability goes in a separate file of the same injection unit.
- `llms.txt` and the version list (pyproject/`__init__`/server.json/CHANGELOG/llms.txt) are derived; never hand-edit.
- Three budget files are read by CI and never written by it: `mypy-baseline.txt` is regenerated by its sync tool (`mypy-baseline sync`); `.github/ruff-baseline.json` (per-rule lint budget) and `.github/monolith-budget.json` (line cap) are maintained by hand and may be tightened in the pull request that earns it.

## Known quirks
- Shared GitButler workspace: another window can unapply your branch mid-run, and the tree stops being the thing you are testing. Before running a ticket's checks, confirm `but status` lists the ticket branch and HEAD equals the baseline SHA recorded at ticket start; when it does not, verify the branch tip in a throwaway worktree and remove it after.
- Large module writes (>10K chars) stale the Maya command port; Qt sessions use the framed channel, temp-file fallback is headless-only.
- `execute_code` with `result_type="JSON"` may return `dict`; handle both. `import X; X.func()` can fail under result capture — pre-import, then call expressions only.
- Git Bash on Windows: never `2> nul`; use `2>/dev/null`. `D-xxx` refs cite the retired decision ledger — read it with `git show '1c5befe^:docs/decision-ledger.md'`; `docs/agents/domain.md` keys its row format and the sub-id notation.
